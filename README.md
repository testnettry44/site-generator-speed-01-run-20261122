A faster drop-in for make.fun's own makefun-site 1.0.0 static site generator: byte-identical output on every case, about 3x less CPU time than the house baseline. `solve.js` is a dependency-free ES module whose `run(input)` returns makefun-site's answer; `main.ts` is the driver the harness runs.

## Run it

```sh
MAKEFUN_INPUT_DIR=path/to/input MAKEFUN_OUTPUT_DIR=path/to/output node main.ts
```
